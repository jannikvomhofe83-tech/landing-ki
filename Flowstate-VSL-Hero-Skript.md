# Flowstate AI — VSL-Skript für das Hero-Video

**Für:** Jannik vom Hofe (Sprecher) · **Ziel:** Hero-Video auf der Landingpage → vorqualifizierte Anfrage über das Formular  
**Zielgruppe:** Partner / Kanzleiinhaber von **Wirtschaftskanzleien**  
**Angebot im Video:** kostenloser **AI Readiness Check** (Bestandsaufnahme + Potenzial-Analyse)  
**Länge:** **Straffe Fassung ~5–5:30 Min (empfohlen)** · Ausführliche Fassung ~7–7:30 Min · Kurzversion ~1:45 Min  
**Stand:** Juli 2026

> **Welche Fassung nehmen?** Für den Hero über Meta-Ads-Traffic → **die straffe Fassung (Abschnitt 2)**. Sie enthält alles Wichtige (Hook, 3 Pain Points, Schlüsselloch-Metapher, Fundament → Automatisierung, Angebot, CTA), nur knapper — und liegt im idealen Längenkorridor für affluente Käufer. Die ausführliche Fassung (Abschnitt 3) ist die Langfassung als Referenz / für eine tiefere Erklärseite. Die Kurzversion (Abschnitt 4) ist der schnellste Schnitt.

## 1. Was die vier Analyse-Videos gelehrt haben (Kurz-Framework)

Analysiert: John Stewart Marketing, **Jeremy Haynes** (65 Min, der Referenz-Mentor der anderen), Ryan Mathews / Funnel Architecture, Conversionly. Alle vier lehren im Kern **dieselbe Struktur**. Die entscheidende Erkenntnis für uns kommt von Jeremy Haynes:

### Der wichtigste Punkt: Wir verkaufen an „affluente" Käufer, nicht an die Masse
Kanzlei-Partner sind wohlhabende, professionelle, skeptische Entscheider. Für diese Gruppe gilt (Gegenteil vom Massenmarkt):

| Affluente Käufer (unser Fall) | Massenmarkt (nicht unser Fall) |
|---|---|
| **Kurz** (2–15 Min, eher kürzer) | Lang (5–60 Min) |
| **Direkt, kein Fluff, autoritativ** | Ausführlich, viel Trust-Aufbau |
| **Konservative, belegbare Aussagen** (untertreiben) | Übertriebene Claims funktionieren |
| **Ruhige, schlichte Präsentation** | Aufwändig designt |
| Keine künstliche Scarcity / keine „Value Stacks" | Scarcity + Rabatte nötig |
| **Authentische Autorität** (echte Sicherheit) | Empathisch, weniger direkt |

→ Das passt **exakt** zu dir als Sprecher, zur Silent-Luxury-Marke und zu unseren Guardrails („keine ROI-Garantien"). Ein VSL für Anwälte ist ein **ruhiges, sachliches, selbstsicheres Experten-Gespräch** — kein Marktschreier-Verkauf. Deshalb ist die straffe Fassung die Standard-Wahl.

### Die gemeinsame VSL-Struktur (auf affluent + kurz optimiert)
Alle vier bauen das VSL wie ein **normales Verkaufsgespräch** auf — nur ohne dass der Gegenüber spricht. Jede Frage, die im Kopf des Zuschauers auftaucht, wird beantwortet, *bevor* er sie stellt (sonst steigt er aus). Prinzip: **Emotion → Logik → Handlungsaufforderung.**

1. **Hook / großes Versprechen** — ICP ansprechen + starke Zahl / Transformation. → Grund zu bleiben.
2. **Problem / „das Messer drehen"** — der *genaue* Schmerz in *ihren* Worten, konkret.
3. **Erste Handlungsaufforderung + nächsten Schritt zeigen** (Jeremy: früh eine CTA setzen, dann weiter vertiefen).
4. **Warum bisherige Versuche scheitern** — das „Aha": das *Warum* ist stärker als das *Wie*.
5. **Die Lösung** — wie *unser* Angebot jeden einzelnen Schmerz löst.
6. **Wer wir sind / warum gerade wir** — echte, glaubwürdige Gründe (keine Vanity-Flexes).
7. **Das Angebot + Wert/Preis** — klar benennen (Jeremy: *immer den Wert/Preis nennen* → qualifiziert).
8. **Zweite CTA + nächste Schritte zeigen.**

### Delivery-Regeln (aus allen vier)
- **Ruhige Energie**, in die Kamera sprechen, Ton wie „mit einem Kollegen beim Kaffee" — aber sachlich-selbstsicher.
- **Look the part:** seriös, neutraler Hintergrund, professionell (nicht flashy). Genau wie es Anwälte von einem seriösen Berater erwarten.
- **Schlichte Optik.** Falls Slides: weißer/schwarzer Hintergrund, minimal. Overdesign wirkt bei affluenten Käufern *unseriöser*.
- **Landingpage schlank halten** (Headline + Video + Formular) → höhere Play-Rate.
- **Thumbnail = echter Schlüsselmoment aus dem Video** (Jannik mit Blickkontakt), kein „Stopp, nicht wegklicken"-Reißer.
- Ruhig 2–3 Takes machen; nicht auswendig ringen, sondern natürlich ablesen.

## 5. Umsetzungs-Checkliste fürs Video

- [ ] **Fassung wählen:** Standard für den Hero = **straffe Fassung (~5–5:30 Min)**. Noch schneller = Kurzversion (~1:45). Ausführliche Fassung (~7–7:30) nur für tiefere Erklär-/Content-Seiten.
- [ ] **Reihenfolge zwingend:** McKinsey-Zahl (88 % / 7 %) → die drei Pain Points → erste CTA (AI Readiness Check) → Schlüsselloch-Metapher (Lösung, 100 % DSGVO) → Wissensfundament → *dann* Automatisierung → warum wir → Angebot → Wert → finale CTA.
- [ ] **Kernbotschaft:** Erst das Wissensfundament, dann Automatisierung. Genau das trennt die 7 % von den 88 % — nicht die Technik.
- [ ] **Name konsistent:** überall **„AI Readiness Check"** (nicht „Effizienz-Analyse") — identisch mit der Landingpage.
- [ ] **Look:** seriös, ruhiger neutraler Hintergrund, professionell — wie Anwälte einen kompetenten Berater erwarten. Kein Flashy-Faktor.
- [ ] **Ton:** ruhig, selbstsicher, direkt. Keine Übertreibungen, keine künstliche Dringlichkeit. Autorität statt Show.
- [ ] **Blickkontakt** in die Kamera, gleichmäßige Energie. Zwei CTAs (③ und ⑨) klar auf das Formular zeigen.
- [ ] **Untertitel Pflicht** (viele schauen ohne Ton aus dem Meta-Feed).
- [ ] **Optionale Visuals:** Schlüsselloch → geöffnete Bibliothekstür (④); 1-2-3-Ablauf (⑦). Minimal halten.
- [ ] **Thumbnail/Poster:** echter Moment von Jannik mit Blickkontakt — kein „Stopp!"-Reißer.
- [ ] **Claims konservativ halten** (Guardrails): keine ROI-/Einsparungs-Garantie · „88 % / 7 %" (McKinsey) · „95 %" (MIT) · „rund 500 €" · KI „100 % DSGVO-konform … ausgelegt/aufgesetzt", nicht „zertifiziert".
- [ ] **Länge real prüfen:** einmal laut sprechen und stoppen. Sprechtempo variiert ±20 %; die Minutenangaben oben sind bei ~118 Wörtern/Min gerechnet.
- [ ] Nach Livegang: **Watch-Time / Drop-off** messen. Steiler Abfall gleich am Anfang → Hook (①) überarbeiten. Gleichmäßiger Abfall → normal.
